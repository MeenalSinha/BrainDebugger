# Contributing

BrainDebugger prioritizes scientific caution, reproducible data handling, and readable engineering.

## Development Principles

- Use real MaleCNS-derived data or clearly label synthetic fixtures.
- Keep unsupported biological claims out of UI text and reports.
- Add validation when touching schema assumptions.
- Keep expensive graph metrics out of request-time paths unless cached or scoped to a small subgraph.

## Local Checks

Run backend endpoint smoke checks and frontend TypeScript checks before submitting changes.
